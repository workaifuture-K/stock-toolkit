StockHero Toolkit

KOL 內容量化系統地基。Threads / Instagram / Facebook 三平台統一 pipeline，per-KOL 獨立 Database + 分析報告。

📌 安裝書籤（開始抓資料） ⏱️ 5 分鐘上手指南 📦 GitHub Repo

這個工具做什麼？

給任何一個 KOL，產出：

  • Database（結構化 JSON）— 給未來 App / Web 直接讀
  • 3 份分析報告（Threads / IG / FB）— 每份 8 段，給主管看的商務報告風格

不做 KOL 之間比較、不做跨領域分析 — 每個 KOL 完全獨立。

怎麼用（3 步驟）

1. 安裝書籤（一次性）
點上面的「安裝書籤」按鈕，把 3 個書籤拖到瀏覽器書籤列。
2. 抓資料
開目標 KOL 的 Threads / IG / FB 主頁 → 點書籤 → 等跑完 → 按「複製」
回 PowerShell 跑 .\save_clipboard.ps1 -Author <kol>
3. 跑 pipeline + 看報告
.\run_kol.ps1 -Author <kol> -Discover
產出位置：domains/<domain>/kols/<kol>/reports/

系統需求

  • Windows 10/11 + PowerShell 5.1+
  • Chromium-based 瀏覽器（Chrome / Edge / Brave / Arc）
  • 登入 IG / FB / Threads 的有效帳號

負責任使用

本工具擷取的是 公開貼文（透過你已登入的瀏覽器 session）。使用前請：

  • 遵守 IG / FB / Threads 的 Terms of Service
  • 未經被分析者同意，不要公開重新發布抓取的內容
  • 遵守當地個資法（GDPR / 個資法等）
  • 不可用於騷擾、起底、未經同意的商業利用

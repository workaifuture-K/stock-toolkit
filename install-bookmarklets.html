作者 — 內容擷取書籤

把書籤拖到 bookmark bar，到對應平台網頁上點即可。每個書籤下方都有 📖 操作說明可展開。

🔍 工具

🔍 檢查資料

列出 localStorage 裡所有 _fb_/_ig_/_threads_ key 的篇數，確認當前擷取狀態。

📖 操作說明
  1. 在 **任意 FB / IG / Threads 頁面** 點此書籤
  2. alert 跳出所有 key 與篇數，例如：_fb_zhao1945: 130 篇
  3. 用途：抓資料前先看 localStorage 有沒有殘留；確認某作者已經抓多少

📸 Instagram

📸 IG 擷取 v8.1

模態框逐篇抓 caption + 日期；ArrowRight 自動換下一篇；失敗 URL 重試 3 次；已訪 URL 不重抓。

📖 操作說明
  1. 開 instagram.com/<作者>/ → 點此書籤抓主貼文
  2. 自動滾 grid → 逐一點開 modal 抓 caption + 日期
  3. 連 60 拍無新篇自動停（或按 panel 上「完成」）
  4. 點 panel 上「複製」→ 跑 save_clipboard.ps1 存到 instagram_<author>_main.json
  5. 跳到 instagram.com/<作者>/reels/ → 再點此書籤抓 Reels
  6. 同樣等跑完 → 「複製」→ save_clipboard.ps1（會合併進主貼文檔）
🗑 清 IG 資料

清掉 localStorage 裡所有 _ig 開頭的 key（包括 _ig_、_ig_vis_、_ig_fail_）。

📖 操作說明
  1. 用途：要重新從零開始抓某作者前，先清掉舊資料避免混在一起
  2. 點此書籤 → confirm 對話框會跳「將清掉 N 個 key，共 X 篇資料。確認？」
  3. 按確認 → 已抓的資料 + 已訪 URL + 失敗紀錄全部消失
  4. ⚠️ 清掉就拿不回來，先確認已經 save_clipboard 存到硬碟

🧵 Threads

🧵 Threads 擷取 v3.5

DOM 優先；自動點貼文內「更多」展開（v3.4 修：限定容器內，不誤點側邊欄）；複製改為 await（v3.5 修：先確認剪貼簿寫入再 alert）；加「下載」按鈕當保底（不受 Threads 剪貼簿權限影響）。

📖 操作說明
  1. 開 threads.com/@<作者> → 點此書籤
  2. 自動滾動 + DOM 抓貼文
  3. 連續 12 拍沒新篇 → 自動停（或按 panel 上「停止」）
  4. 方式 A（推薦）：點「複製」→ save_clipboard.ps1 存檔
  5. 方式 B（保底）：點「下載」→ 瀏覽器下載 threads_<author>_<時間>.json 到 Downloads 資料夾
  6. 如果「複製」alert 顯示失敗，直接用「下載」

清掉 localStorage 裡所有 _threads 開頭的 key。

📖 操作說明
  1. 用途：要重新從零開始抓某作者前，先清掉舊資料避免混在一起

  3. 按確認 → 已抓資料全部消失
  4. ⚠️ 清掉就拿不回來，先確認已經 save_clipboard 存到硬碟

📘 Facebook

📘 FB 擷取 v5.4 (自主滾動)

書籤自主滾動（不需 PowerShell）；自動偵測 home/posts/photos/videos；主時間軸與影片必須分兩次跑、分兩次存，最後跑 merge_fb.ps1 合併。

📖 操作說明
  1. ⚠️ FB SPA 換頁會清 localStorage，主頁與影片必須分兩次抓
  2. 開 facebook.com/<作者>/ → 點此書籤抓主時間軸
  3. 等「滾完了」橘色提示出現 → 點 panel 上「複製」
  4. 跑 save_clipboard.ps1 存到 facebook_<author>.json
  5. 網址改 facebook.com/<作者>/videos → 重點此書籤
  6. 一樣等→「複製」→ 跑 save_videos.ps1 存到 facebook_<author>_videos.json
  7. 跑 merge_fb.ps1 合併兩個檔（dedup by content hash）
